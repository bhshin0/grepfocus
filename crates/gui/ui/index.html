    Settings

    A settings password adds friction against weakening your blocks on a whim. When set, changing configuration (adding, editing, or deleting blocks and schedules) requires unlocking first. Starting blocks never needs the password, and neither does taking a break — unless the block uses password-locked breaks. The daemon relocks on restart. Note: this is friction, not security — anyone with root can bypass it.
