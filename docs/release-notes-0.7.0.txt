GrepFocus now counts how often a blocked site is reached for while a block is running (with Instant breaks on): the Status tab shows the count on the running block, the Stats tab gains a "Sites blocked" total and a "Most attempted" list for the last 30 days, and an optional nudge in Settings — off by default — shows a desktop notification naming the site, at most once per site every 15 minutes.
Desktop notifications now also tell you when a break has one minute left and when it is over, when a pomodoro switches between focus and break and when the set is complete or stopped, and when GrepFocus closes a blocked app; the existing on/off switch in Settings covers them all.
A schedule window may run past midnight (22:00 for 4 h ends at 02:00 the next day) and last up to 24 hours; the Week grid draws the part after midnight in the next day's column. On DST nights a window ending in or straddling the skipped hour keeps its length, one ending in the repeated hour ends at the later instant — never shorter.
Editing, disabling or deleting a schedule no longer ends a block it has already started: the block runs to the end of the window it fired for, and the change applies from the next window.
Changing the system clock during a block no longer shortens it: while anything runs, block timing follows elapsed time (sleep included, so a block still ends on time after a suspend), and a service restart keeps that time base until the next reboot.
Export and import of blocks and schedules, on the Block list tab: Export writes a plain JSON copy to your Downloads folder (never the password, license or stats); Import merges a file into the saved configuration — a name already in use gets "(imported)" — or replaces it when nothing is running.
An import goes through the same checks as saving, license checks included: a file the license does not cover is refused as a whole, and nothing from it is saved.
